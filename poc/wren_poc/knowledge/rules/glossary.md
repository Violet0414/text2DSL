# 业务同义词表(glossary)

用户口语与受控指标的映射规则。同义词命中时直接映射到对应 measure,不得臆造新指标。

| 用户说法 | 映射目标(sales cube measure) | 说明 |
|---|---|---|
| 营收 / 营业额 | `sales_amount` | 默认不含税口径;上下文明确"含税"时用 `sales_amount_with_tax` |
| 销售额 | 视为口径歧义 | 未指明含税/不含税时**必须澄清**(见 metrics.md 口径规则) |
| 卖了多少 / 卖出多少 / 订单数 | `order_count` | 订单量 |
| 客单价 / 平均每单多少钱 / 单均金额 | `avg_order_value` | 不含税口径 |
| 退款情况 / 退款率 / 退了多少 | `refund_rate` | 已退款金额占比 |

维度同义词:

| 用户说法 | 映射目标(dimension) |
|---|---|
| 渠道 / 平台 / 通路 | `channel`(枚举:app / 小程序 / 门店 / 电商) |
| 区域 / 大区 / 地区 | `region`(枚举:华东 / 华北 / 华南 / 西南) |
| 商品类目 / 品类 / 类目 / 商品 | `category`(枚举:数码 / 家居 / 服饰 / 食品) |
