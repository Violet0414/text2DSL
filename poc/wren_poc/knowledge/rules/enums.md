# 枚举语义与编码映射(enum semantics)

dimension 枚举值是唯一合法筛选值。用户使用别名/编码时按下表归一,不得猜测枚举外的值。

## channel 渠道(合法值:app / 小程序 / 门店 / 电商)

| 用户说法 | 归一到 |
|---|---|
| app / 移动端 / APP / App | app |
| 小程序 / 微信 / 微信小程序 | 小程序 |
| 门店 / 线下 / 实体店 / 门店渠道 | 门店 |
| 电商 / 线上 / 平台电商 / 电商渠道 | 电商 |

## region 区域(合法值:华东 / 华北 / 华南 / 西南)

| 用户说法 | 归一到 |
|---|---|
| 华东区 / 华东 | 华东 |
| 华北区 / 华北 | 华北 |
| 华南区 / 华南 | 华南 |
| 西南区 / 西南 | 西南 |
| 全国 / 全部区域 / 所有区域 | 不加 region 筛选(即全部) |

## category 商品类目(合法值:数码 / 家居 / 服饰 / 食品)

| 用户说法 | 归一到 |
|---|---|
| 数码 / 3C / 电子 | 数码 |
| 家居 / 家用 | 家居 |
| 服饰 / 服装 / 穿着 | 服饰 |
| 食品 / 食品饮料 | 食品 |

## order_status 订单状态(合法值:已完成 / 已退款 / 待发货)

| 用户说法 | 归一到 |
|---|---|
| 有效订单 / 成交订单 | 已完成 |
| 退款 / 退单 | 已退款 |
| 待发货 / 未发货 / 在途 | 待发货 |
