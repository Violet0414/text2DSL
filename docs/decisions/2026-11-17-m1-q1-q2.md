# M1 决策记录:PRD 开放问题 Q1/Q2 定案(2026-11-17)

## Q1 规划模型选型 — 沿用当前模型,对比延后

- **决定**:M1 锁定当前模型 `claude-sonnet-5-5`(经火山 codingPlan 网关
  `ark.cn-beijing.volces.com/api/coding`,ANTHROPIC_AUTH_TOKEN Bearer 凭据;
  PoC 报告实测后端为 doubao-seed-2-1-turbo)。
- **理由**:用户未提供候选模型清单;PoC 58/58 基线即该模型产出,零漂移风险;
  LLM 客户端经 LlmClient 协议注入 + `CHATBI_LLM_MODEL` 环境变量,换模型零代码改动。
- **延后触发条件**:M5/NFR-1 优化期(P95 达标需要更小模型)或用户给出候选清单时,
  用 `poc/eval/run_eval.py --tag model-<name>` 对比评测后重新定案。
- **成本口径**:codingPlan 为订阅额度;全量回归消耗量级与 PoC 单轮相当。

## Q2 会话上下文存储 — Repository 接口 + 内存/SQLite 双实现

- **决定**:M1 不引入 Redis。`SessionRepository`/`MiningRepository` 协议 +
  `store/memory.py`(单进程)+ `store/sqlite.py`(单机持久化,默认装配)。
- **理由**:满足 §5.3 状态外置要求的最简方案;部署环境确认后平替 Redis 只换实现。
- **重评估触发**:M2 会话管理(历史回看/trace 回放)需要跨进程共享状态时。
